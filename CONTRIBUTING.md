# Contributing

Thank you for helping. Keep changes small and clear.

1. Open an issue first for anything large.
2. Fork, make a branch, make one change.
3. Add or update a unit test. Run: `python3 -B -m unittest discover -s tests -q`
4. Do not add secrets, personal data, logs, model weights, or PDFs. CI scans for secrets and will fail.
5. Only add dependencies under MIT, Apache-2.0, BSD, GPL-3.0, LGPL or AGPL. No GPL-2.0-only, SSPL, or proprietary code.
6. By sending a contribution you agree it is licensed GPL-3.0-only.
7. Be kind. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
