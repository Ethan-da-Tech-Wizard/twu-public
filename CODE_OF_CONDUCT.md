# Code of Conduct

This project follows the spirit of the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Our pledge.** We want a harassment-free, welcoming project for everyone, whatever their age, body, disability, ethnicity, gender identity, experience, nationality, appearance, race, religion, or orientation.

**Do:** be respectful, give and accept feedback with grace, own mistakes, focus on what is best for the community.

**Do not:** use sexual language or imagery, insult or troll, harass in public or private, publish others' private information, or act in ways that are inappropriate in a professional setting.

**Enforcement.** Maintainers may remove, edit, or reject comments, commits, and issues that break these rules, and may ban repeat offenders. Report conduct concerns privately through the Security tab (Report a vulnerability) on this repository, or by contacting the maintainer through GitHub.
